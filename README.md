## 🎯 نبذة عن المشروع

تطبيق **Flutter** متكامل لتسجيل المستخدمين وتسجيل الدخول مع التحقق من البيانات، متصل مع **PHP** و **MySQL** (XAMPP) من خلال API. تم تصميم الواجهة باللغة العربية مع التركيز على تجربة مستخدم سلسة وجذابة.

## 💡 الفكرة الأساسية للمشروع

هذا التطبيق هو **نموذج تسجيل ذكي** يتحقق من صحة البيانات قبل إرسالها إلى قاعدة البيانات.

### 🎯 تخيلها بشكل واقعي

تخيل أنك تريد التسجيل في موقع ما:

1. **تكتب اسمك** → يتأكد أن الاسم طويل كافي
2. **تكتب بريدك** → يتأكد أن الإيميل صحيح
3. **تكتب كلمة المرور** → يظهر لك كم هي قوية
4. **تأكيد كلمة المرور** → يتأكد أنها مطابقة
5. **رقم الهاتف** → يتأكد أنه صحيح

👉 بعدها يتم إرسال البيانات إلى قاعدة البيانات عبر API

## 🏗️ تفكيك التطبيق خطوة بخطوة

### 1️⃣ التطبيق الرئيسي (MyApp)
- يحدد اتجاه الكتابة (RTL)
- يضبط الثيم والألوان
- يحدد الشاشة الأولى

### 2️⃣ الشاشة الأولى (FirstScreen)
- نموذج التسجيل الكامل
- يحتوي على 5 حقول
- التحقق من البيانات لحظياً

### 3️⃣ التحقق من صحة البيانات (Validation)
- الاسم: 10-20 حرف
- الإيميل: صيغة صحيحة
- كلمة المرور: 8 أحرف + أرقام + رموز
- تأكيد كلمة المرور: تطابق
- الهاتف: أرقام فقط

### 4️⃣ الاتصال مع API
- إرسال البيانات إلى PHP
- معالجة الرد (نجاح أو فشل)
- تسجيل دخول تلقائي للمستخدمين الموجودين

### 5️⃣ الشاشة الثانية (SecondScreen)
- عرض رسالة نجاح
- ترحيب بالمستخدم
- إظهار بيانات المستخدم
